## 📝 Task Implementation Summary

### Part 1: Creating and Editing Digital Text Content (CLO8, CLO9)
* **Task 1.1:** Drafted a structured report on *"Applications of Digital Technology in Learning"* using Google Docs. Utilized AI tools for structural suggestions, standardized styling with Times New Roman 12pt font, 1.5 line spacing, standard margins, and embedded royalty-free illustrations. Exported deliverable: [Buoi05_Nhom7_NV1_1.pdf](nhiemvu1/Buoi05_Nhom7_NV1_1.pdf).
* **Task 1.2:** Online team collaboration via Google Docs:
  * Shared access among team members, leveraging the **Suggesting** mode for peer review and editorial feedback.
  * Interacted via **Comments** politely, constructively, and adhering strictly to netiquette.
  * Documented editorial history using **Version History** and captured screenshot evidence at [anhchup.png](nhiemvu1/anhchup.png).
  * Published finalized collaborative document: [Buoi05_Nhom7_NV1_2.pdf](nhiemvu1/Buoi05_Nhom7_NV1_2.pdf).

### Part 2: Creating and Editing Multimedia Content (CLO9, CLO12)
* **Task 2.1 (Infographic):** Designed an infographic on Canva leveraging Canva AI (Magic Design) with the prompt: *"Create an infographic on the benefits of digital technology in education"*. Maintained a consistent blue-white color palette and integrated intuitive icons. Exported deliverable: [infographic.jpg](infographic.jpg).
* **Task 2.2 (MP4 Video):** Produced a short video (< 1 minute) highlighting digital learning solutions using CapCut. Utilized copyright-free stock footage/audio and automated Text-to-Speech AI voiceover. Deliverable file: [Nhiemvu2.2.mp4](Nhiemvu2.2.mp4).

### Part 3: Creating and Managing Source Code with Git/GitHub (CLO9)
* **Task 3.1:** Developed a responsive web showcase [index.html](index.html) with AI Assistant support. The webpage includes:
  * Full-featured media presentation containing the Infographic and an HTML5 MP4 video player with standard playback controls.
  * Prominent, transparent attribution and copyright disclaimer section.
* **Task 3.2:** Initialized Git repository, committed deliverables, managed branches, and deployed the live web application via **GitHub Pages** at: [https://MapperZ1.github.io/Nhom7_TH_5/](https://MapperZ1.github.io/Nhom7_TH_5/).

## Transparent & Ethical AI Statement (CLO12)

| Content Item | AI Tool Used | Prompt / Implementation Method | Human Evaluation & Oversight |
|:---|:---|:---|:---|
| **Text & Scriptwriting** | Google Bard / Gemini / ChatGPT | *"Write a 150-word paragraph about the application of digital technology in learning"* | Screened for factual accuracy and bias, refined academic tone, verified grammar. |
| **Infographic** | Canva AI (Magic Design) | *"Create an infographic on the benefits of digital technology in education"* | Filtered excessive text, selected relevant icons, balanced visual hierarchy. |
| **Video & Voiceover** | CapCut AI | Text-to-Speech synthesis converting Vietnamese script into natural voiceover | Reviewed audio cadence and pauses, synchronized with scene transitions. |
| **Source Code (HTML/CSS)** | AI Coding Assistant | *"Write HTML code to display an infographic and MP4 video on a webpage"* | Optimized relative file paths, implemented responsive layout, verified cross-browser compatibility. |
